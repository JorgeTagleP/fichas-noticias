# Fichas de noticias del norte – Una Sola Fuerza

Lee cada hora las noticias de Tumbes, Piura, Lambayeque y Cajamarca, las convierte en fichas y
arma conclusiones para enfrentar la emergencia por El Niño: dónde hay más peligro para las
personas, qué hacer, salud, brechas en la atención, pronóstico y proyectos para el futuro.

**La página:** se publica sola en GitHub Pages (ver [ACTIVAR-EN-GITHUB.md](ACTIVAR-EN-GITHUB.md)).

> Son noticias de prensa, todas en nivel **D – Sin verificar**. Las cifras oficiales son las de
> INDECI, SENAMHI y MINSA; se citan, no se reinterpretan.
